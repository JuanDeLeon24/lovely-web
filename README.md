# Lovely · LV Accesorios — sitio web (vista previa)

Sitio estático de avance para revisión del cliente. Publicado con GitHub Pages.

## Estructura
- `index.html` Home · `tienda.html` Catálogo con filtros · `producto.html?id=…` Detalle
- `checkout.html` Compra en 3 pasos (pago simulado) · `cuenta.html` Perfil · `nosotros.html` · `ayuda.html` FAQ + contacto
- `css/styles.css` estilos (mobile first, paleta y tipografías del manual de marca)
- `js/data.js` **catálogo y datos de contacto** (WhatsApp, redes): edita aquí productos, precios y enlaces
- `js/main.js` interacciones (carrito, filtros, galería, checkout)
- `assets/` logos e iconos

## Pendiente de contenido
Fotos reales, precios, testimonios, número de WhatsApp, usuarios de redes, tiempos y tarifas de envío, políticas de garantía y cambios.

El sitio tiene `noindex` mientras sea una vista previa, para que Google no lo indexe.
