Panel administrativo

Edita productos, fotos, precios y datos de venta. Los cambios se guardan en el repositorio de la tienda y la página se actualiza en 1 o 2 minutos.

¿Cómo obtengo el token?
  1. En GitHub abre Settings → Developer settings → Personal access tokens → Fine-grained tokens y pulsa Generate new token.
  2. En Repository access elige Only select repositories y marca lovely-web.
  3. En Permissions → Repository permissions pon Contents: Read and write.
  4. Copia el token y pégalo aquí. No lo compartas: quien lo tenga puede editar la tienda.
